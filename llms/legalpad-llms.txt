# Legalpad

> Legalpad (Legalpad Inc, Seattle) was a startup-focused US work-visa and immigration company
> that paired software with staff immigration attorneys. Founded by Todd Heine and Sara Itucas
> out of Techstars Seattle (2017), it was acquired by Deel in 2022 and now operates as Deel
> Immigration. Legalpad never published a public API, developer portal, documentation or SDK.
> This file is generated by the API Evangelist enrichment pipeline from the company profile and
> archived provider material; there is no live legalpad.io surface to link to.

## Status

- Status: acquired — Deel, 2022; operated as "Legalpad by Deel" inside Deel Immigration
- API surface: none (no public API, portal, docs, SDK, CLI, MCP server or event surface)
- Former website: https://legalpad.io/ — retired after 2024, no DNS A record as of 2026-07-19
- Successor: [Deel Immigration](https://www.deel.com/immigration/)

## Services (as published while operating)

Temporary work visas: O-1, H-1B, L-1A, L-1B, TN, E-1/E-2, E-3, B-1, UAE Golden Visa.
Employment-based green cards: EB-1A, EB-1B, EB-1C, EB-2 PERM, EB-2 NIW.
